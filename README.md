# Persona Lab Compass

Открытая подборка технологий для создания ИИ-персонажей.

[Открыть Compass](https://course.personalabs.ru/compass/) · [Шаблон личного рейтинга](https://github.com/3ndetz/compass-rating-template)

Подборка содержит ссылки на первоисточники. Для свежих рейтингов, цен и большего каталога используйте сервис. Предложения и исправления принимаются через issues и pull requests.

## Синтез речи

- [Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS) — Семейство для потокового синтеза речи, клонирования и дизайна голоса.

## Изображения

- [MOSS-Image](https://openmoss.ai/MOSS-Image/) — Открытая модель изображений на 5B параметров; управление композицией через JSON и координаты объектов.
- [Krea 3](https://www.krea.ai/blog/introducing-krea-3) — Генерация и редактирование изображений; по данным Krea, до 6 референсов и 2K на собственной платформе.
- [FLUX 3](https://www.krea.ai/models/flux-3) — Семейство для генерации и редактирования изображений и видео; доступность зависит от провайдера.

## Агентные harness

- [Codex](https://github.com/openai/codex) — Агент для работы с кодом и инструментами в терминале.
- [Claude Code](https://github.com/anthropics/claude-code) — Агент для работы с кодовой базой и инструментами.
- [OpenCode](https://github.com/anomalyco/opencode) — Открытый агент для разработки с поддержкой разных провайдеров.
- [Aider](https://github.com/Aider-AI/aider) — Парное программирование в терминале с использованием моделей.
- [OpenHands](https://github.com/OpenHands/OpenHands) — Платформа агентной разработки и выполнения задач.
- [Goose](https://github.com/block/goose) — Расширяемый агент для работы с инструментами.
- [Cline](https://github.com/cline/cline) — Агент программирования для редактора и терминала.

## Память и RAG

- [LightRAG](https://github.com/HKUDS/LightRAG) — Поиск и генерация с использованием графа знаний.
- [MemPalace](https://github.com/MemPalace/mempalace) — Локальная память агента: сохранение текста, семантический поиск и граф связей.
- [Mem0](https://github.com/mem0ai/mem0) — Слой памяти для персонализированных ИИ-приложений.
- [Graphiti](https://github.com/getzep/graphiti) — Временной граф знаний для агентных приложений.
- [LlamaIndex](https://github.com/run-llama/llama_index) — Инструменты для построения приложений на собственных данных и RAG.
- [Haystack](https://github.com/deepset-ai/haystack) — Пайплайны поиска и генерации на собственных данных.
- [Agent Workplace](https://github.com/3ndetz/agent-workplace) — Рабочее пространство агента с файловой памятью и связанными заметками.

## Агентные системы

- [Pipecat](https://github.com/pipecat-ai/pipecat) — Пайплайны голосовых и мультимодальных агентов в реальном времени.
- [LiveKit Agents](https://github.com/livekit/agents) — Фреймворк для голосовых и мультимодальных агентов.
- [LangGraph](https://github.com/langchain-ai/langgraph) — Построение управляемых графов и состояний агентных приложений.
- [AutoGen](https://github.com/microsoft/autogen) — Средства построения приложений с несколькими агентами.
- [CrewAI](https://github.com/crewAIInc/crewAI) — Оркестрация команд агентов и их задач.
- [Model Context Protocol](https://modelcontextprotocol.io/) — Протокол подключения инструментов и источников данных к приложениям ИИ.
- [Mineswarm](https://mineswarm.personalabs.ru/) — Система персонажей и агентов Persona Lab.

## Локальный запуск

- [Ollama](https://github.com/ollama/ollama) — Локальный запуск и управление языковыми моделями.
- [llama.cpp](https://github.com/ggml-org/llama.cpp) — Локальный запуск языковых моделей, включая GGUF и квантизованные варианты.
- [vLLM](https://github.com/vllm-project/vllm) — Сервер и движок инференса языковых моделей.

## Данные

`catalog.json` содержит идентификаторы, описания и ссылки подборки. Источники сохраняют свои права и условия использования. Рейтинги Arena и данные внешних API доступны через сервис и указанные там источники.
